# ALFRED — Adaptive Local-First AI Assistant

> Adaptive local-first AI assistant focused on interaction, emotional UX and accessibility.

🇫🇷 French version available here: [README_FR.md](README_FR.md)

## Overview

ALFRED is an experimental adaptive AI assistant project designed to support daily organization, reduce mental load and explore more human-centered interactions between people and artificial intelligence.

The project combines local-first architecture, emotional UX, avatar-based interaction, memory and knowledge systems, voice interaction, accessibility-oriented design, and responsible AI principles.

## Current Status

ALFRED is a work in progress.

The current prototype explores:

- local memory system
- long-term knowledge structure
- voice input and output experiments
- emotional response logic
- dashboard and monitoring interface
- avatar and visual identity exploration
- Android and multi-device architecture research
- local-first and security-by-design principles

This public repository is intended as a clean, contributor-friendly version of the project. Private data, personal logs, sensitive configuration and experimental local files are intentionally excluded.

## Design Philosophy

- **Human-centered AI** — technology should support people, not overwhelm them.
- **Local-first** — personal data should remain under user control whenever possible.
- **Emotional design** — interface and interaction should acknowledge real human contexts.
- **Accessibility by design** — the assistant should be usable by people with different needs and constraints.
- **Transparency** — the user should understand what the assistant does and why.
- **Progressive complexity** — start simple, test often, improve continuously.
