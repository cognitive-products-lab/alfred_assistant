Oui, c’est **la solution la plus simple, la plus robuste et la plus facile à exploiter dans ALFRED**.

Il faut abandonner la multiplication de calques séparés pour les sourcils, les paupières et les iris. Chaque combinaison **yeux + sourcils** devient une base faciale complète sans bouche. La bouche est ensuite ajoutée indépendamment selon l’émotion ou le son prononcé.

# Architecture retenue

## 1. Image corporelle de référence verrouillée

Fichier principal :

```text
alfred_body_no_face.png
```

Il conserve strictement :

* le canvas de `1024 × 1536 px` ;
* la position du corps ;
* la position de la tête ;
* les cheveux ;
* l’oreille ;
* le costume ;
* l’éclairage ;
* les proportions ;
* la transparence.

Ce fichier ne devra plus jamais être redimensionné, recadré ou redessiné.

---

## 2. Bases d’expression sans bouche

Chaque base contient :

* le corps original ;
* les sourcils ;
* les yeux ;
* les iris et pupilles ;
* éventuellement le nez s’il est visible ;
* **aucune bouche**.

Tous les fichiers restent en `1024 × 1536 px`, avec exactement le même placement.

Il n’est donc plus nécessaire d’assembler séparément :

```text
corps + sourcils + yeux + pupilles
```

On charge directement :

```text
base_expression_sans_bouche + calque_bouche
```

C’est beaucoup plus propre.

# Animation du clignement

Créer seulement trois bases supplémentaires :

| Code   | Fichier                            | État                  |
| ------ | ---------------------------------- | --------------------- |
| `BL00` | `alfred_blink_open_no_mouth.png`   | Yeux ouverts          |
| `BL01` | `alfred_blink_half_no_mouth.png`   | Paupières à mi-course |
| `BL02` | `alfred_blink_closed_no_mouth.png` | Yeux fermés           |

Séquence :

```text
BL00
BL01
BL02
BL01
BL00
```

Durée totale recommandée :

```text
120 à 180 millisecondes
```

Le clignement peut être déclenché aléatoirement toutes les trois à sept secondes.

# 3. Calques de bouche indépendants

Les bouches doivent être exportées sur un canvas transparent de :

```text
1024 × 1536 px
```

Même si seule une petite zone contient des pixels.

Elles seront placées automatiquement au bon endroit, sans calcul de coordonnées supplémentaire.

Structure :

```text
alfred_face_neutral_no_mouth.png
+
mouth_V09_A.png
=
ALFRED prononçant le son « A »
```

À chaque image de l’animation, le moteur affiche **une seule bouche**. Les bouches ne doivent jamais être empilées les unes sur les autres.

# Première série à produire

Pour éviter de lancer immédiatement une usine à expressions, la première version devrait comprendre :

### Bases sans bouche

1. Neutre
2. Disponible
3. Écoute attentive
4. Bienveillant
5. Heureux
6. Concentré
7. Sérieux
8. Préoccupé
9. Empathique
10. Triste
11. Surpris
12. Sceptique
13. Alerte
14. Fatigué
15. Yeux fermés
16. Clignement intermédiaire

### Bouches

* 6 bouches émotionnelles essentielles ;
* 15 visèmes de parole.

Cela représente seulement :

```text
16 bases faciales
+
21 calques de bouche
=
37 fichiers
```

C’est infiniment plus maîtrisable que 150 calques indépendants, tout en couvrant déjà l’essentiel des interactions. Ensuite, les variantes pourront être ajoutées sans toucher au moteur d’affichage.

La règle d’or sera donc :

> **Les yeux et les sourcils définissent l’état émotionnel général. La bouche définit soit l’émotion au repos, soit le son prononcé.**
