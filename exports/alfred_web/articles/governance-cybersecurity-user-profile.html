& AI User Profile

How I designed an ethical, secure, and compliant data system for an adaptive AI assistant — from psychological profiling to SOC.

📅 June 2026 👩‍💻 Céline Rousselot 🏷️ GDPR · AI Act · ANSSI · Lean Six Sigma ⏱️ 12 min read

🎯 Context & problem statement

As part of the ALFRED project — a local-first adaptive AI assistant (Cognitive Products Lab) — I had to solve a structural challenge: how do you build a rich, accurate user profile that genuinely personalises the AI without compromising security, privacy, or regulatory compliance?

The answer couldn't be partial. It had to simultaneously cover the scientific dimension (validated psychological frameworks), the technical dimension (encryption, local-first, auditability) and the regulatory dimension (GDPR, AI Act, NIS2, ANSSI).

The quality of input data determines the quality of AI adaptation. An approximate profile produces an approximate AI. A secure profile builds lasting trust. — ALFRED design principles, CPL 2026

🧠 Psychological profiling system

Rather than collecting surface-level data (age, stated preferences), I built a system grounded in scientifically validated psychological frameworks, delivered as a natural conversation with ALFRED.

🪞

Personality — TIPI/OCEAN

Big Five (Gosling et al., 2003). 10 items, 5 stable dimensions. Reviewed annually.

❤️

Emotional Intelligence

TEIQue-SF (Petrides, 2009). Well-being, self-control, emotionality, sociability.

🧩

Cognitive style — SDT

Self-Determination Theory. Autonomous vs controlled motivation. Reviewed quarterly.

⚡

Resilience & stress — PSS + CD-RISC

Cohen (1983) + Connor-Davidson (2007). Monthly indicator — the most variable.

🏆

Engagement — UWES-9

Schaufeli & Bakker (2004). Vigour, dedication, absorption. Monthly — critical for burnout.

🎯

Well-being — SWLS + PANAS

Diener (1985) + Watson (1988). Life satisfaction and positive/negative affect.

Conversational format — non-intrusive UX

Each questionnaire is delivered question by question within the ALFRED conversation, as a natural dialogue. The user can pause and resume at any time. Each answer is saved immediately. Partial scores are available from 60% completion onwards.

△ The performance golden triangle

This architecture follows a Lean Six Sigma logic: every investment in data quality reduces operational costs and increases perceived value — and therefore revenue.

QUALITY Accurate data → accurate AI
Tailored UX → satisfaction
COST Zero breaches → fewer incidents
Compliance from V1 → no debt
REVENUE Trust → retention
Compliance → B2B differentiator

⚙️ DMAIC methodology applied

The entire system was structured using the DMAIC (Lean Six Sigma) method — each phase documented and traceable.

D Define Psychological dimensions to measure, GDPR scope, products in scope
M Measure Validated questionnaires, normalised scores 0–100, periodicity
A Analyze ProfileAnalyzer, mapping matrix, scores → ALFRED parameters
I Improve Adapted ALFRED behaviour, personalised UX, periodic re-testing
C Control SOC, audit trail, GDPR, CNIL/ANSSI alerts, annual reviews

🔒 Governance & Cybersecurity

Data governance is not a post-design add-on — it is embedded from the first commit (Security by Design, Privacy by Design).

Regulatory framework covered

GDPR art. 30 — Processing register
French Data Protection Act / CNIL
EU AI Act 2024/1689 — Product classification
NIS2 2022/2555 — Cybersecurity
Cyber Resilience Act 2024/2847
ANSSI — Technical recommendations
ISO 27001:2022 — Compliance target
HDS — Health Data Hosting (ARTHUR)

Traceability schema — every data point is auditable

Each processing operation is documented with: who created / accessed / modified / deleted, when, why, under which role — and data that must never leave the user's device is explicitly identified.

Progressive SOC — 3 levels

🔎

Level 1 — Now

Anonymised log collection, daily manual review, CERT-FR/ANSSI monitoring, critical alerts.

⚡

Level 2 — V2 (12 months)

Lightweight SIEM (Wazuh), automated detection rules, response playbooks.

🏢

Level 3 — V3 (if growth)

ANSSI-certified MSSP, 24/7 SOC, bi-annual penetration testing.
