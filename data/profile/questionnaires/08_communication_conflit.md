### Construits mesurés

Le modèle Thomas-Kilmann définit 5 modes de gestion des conflits selon **deux axes** :

- **Axe vertical — Assertivité** : degré auquel vous cherchez à satisfaire VOS propres intérêts
- **Axe horizontal — Coopération** : degré auquel vous cherchez à satisfaire les intérêts d'AUTRUI

```
                    ASSERTIVITÉ ÉLEVÉE
                           |
          COMPÉTITION      |      COLLABORATION
          (Fort/Faible)    |      (Fort/Fort)
                           |
--------- Faible --------- + --------- Élevée -------- COOPÉRATION
                           |
          ÉVITEMENT        |      ACCOMMODEMENT
          (Faible/Faible)  |      (Faible/Fort)
                           |
                    ASSERTIVITÉ FAIBLE
                       COMPROMIS
                   (position centrale)
```

| Mode | Assertivité | Coopération | Description |
|------|------------|-------------|-------------|
| **Compétition** | Élevée | Faible | Défend fermement sa position, orientation résultat, win-lose |
| **Collaboration** | Élevée | Élevée | Recherche win-win satisfaisant les deux parties |
| **Compromis** | Moyenne | Moyenne | Accord partiel, concessions mutuelles |
| **Évitement** | Faible | Faible | Reporte ou esquive le conflit |
| **Accommodement** | Faible | Élevée | Cède à l'autre, priorise la relation sur ses intérêts |

*Pour chaque situation, choisissez la lettre (A ou B) correspondant à l'approche qui vous ressemble le plus, même si ni l'une ni l'autre n'est exactement ce que vous feriez. Notez votre choix (A ou B) dans la colonne de droite.*

| **IP1** | **A** : Je maintiens ma position et cherche à convaincre l'autre que j'ai raison. | **B** : Je cherche un accord où chacun obtient quelque chose. | |
| **IP2** | **A** : Je préfère éviter le sujet plutôt que de risquer une confrontation. | **B** : Je fais tout ce qui est nécessaire pour trouver une solution qui satisfait tout le monde. | |
| **IP3** | **A** : J'accepte ce que l'autre propose pour préserver notre relation. | **B** : Je m'assure que mes intérêts essentiels sont pris en compte dans l'accord final. | |

**Partie B — Scores Likert par mode :**

| Mode | Items | Calcul |
|------|-------|--------|
| Compétition | CC1, CC2, CC3 | Somme (3-15) |
| Collaboration | CC4, CC5, CC6 | Somme (3-15) |
| Compromis | CC7, CC8, CC9 | Somme (3-15) |
| Évitement | CC10, CC11, CC12 | Somme (3-15) |

**Score composé final** : Pondération 40% score ipsatif normalisé + 60% score Likert normalisé, puis normalisation 0-100.

---

### Interprétation

**Mode dominant** : le mode avec le score composite le plus élevé guide vos réactions automatiques sous stress.

**Mode de repli** : 2e score le plus élevé — utilisé quand le mode dominant est insuffisant.

**Pas de "bon" ou "mauvais" mode** : chaque mode est adapté à certains contextes :
- **Compétition** : utile pour les décisions urgentes ou face à l'injustice
- **Collaboration** : idéale pour les problèmes complexes à fort enjeu relationnel
- **Compromis** : efficace quand les deux parties ont des intérêts légitimes et un temps limité
- **Évitement** : pertinent pour les conflits mineurs ou quand il faut laisser les émotions retomber
- **Accommodement** : sage quand vous avez tort ou quand la relation prime sur le sujet
