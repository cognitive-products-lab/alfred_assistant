# Contributing to ALFRED

Thank you for your interest in ALFRED.

ALFRED is an adaptive local-first AI assistant project focused on human-centered interaction, emotional UX, accessibility, privacy and long-term usefulness.

## What kind of help is welcome?

### UX / UI

- Figma mockups
- screen redesign
- accessibility improvements
- user flows
- onboarding ideas
- emotional UX patterns

### Avatar & Motion

- expressive avatar states
- facial expressions
- sprite logic
- animation systems
- voice-synchronized visual feedback

### Frontend / Interface

- dashboard structure
- React or Python UI prototypes
- responsive layouts
- design system foundations

### Documentation

- README improvements
- architecture diagrams
- roadmap clarification
- accessibility notes
- contribution guidelines

## How to contribute

1. Open an issue to discuss your idea.
2. Explain the problem or improvement clearly.
3. Add screenshots, mockups or examples if useful.
4. Keep contributions focused and understandable.
5. Prefer small contributions over large unclear changes.

## Private data and security

Do not commit API keys, personal logs, private memories, real personal data, credentials, local configuration files, private screenshots or sensitive system paths.
