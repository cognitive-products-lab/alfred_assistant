# Contribuer à ALFRED

Merci pour votre intérêt pour ALFRED.

ALFRED est un projet d’assistant IA adaptatif local-first, centré sur l’interaction humaine, l’UX émotionnelle, l’accessibilité, la protection des données et l’utilité concrète dans la durée.

## Quels types d’aide sont recherchés ?

### UX / UI

- maquettes Figma
- amélioration d’écrans
- accessibilité
- parcours utilisateurs
- onboarding
- patterns d’UX émotionnelle

### Avatar & Motion Design

- états d’avatar expressif
- expressions faciales
- logique de sprites
- systèmes d’animation
- retour visuel synchronisé avec la voix

### Frontend / Interface

- structure du dashboard
- prototypes React ou Python
- interfaces responsives
- bases de design system

### Documentation

- amélioration du README
- schémas d’architecture
- clarification de la roadmap
- notes d’accessibilité
- règles de contribution

## Comment contribuer ?

1. Ouvrir une issue pour discuter de l’idée.
2. Expliquer clairement le problème ou l’amélioration.
3. Ajouter des captures, maquettes ou exemples si utile.
4. Garder les contributions ciblées et compréhensibles.
5. Privilégier les petites contributions claires.

## Données privées et sécurité

Ne jamais publier clés API, journaux personnels, mémoires utilisateur privées, données personnelles réelles, identifiants, fichiers de configuration locaux, captures privées ou chemins système sensibles.
